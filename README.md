# Address Book Management System (C)

> A modular Command-Line Contact Management System built using C and Makefile.

---

## Overview

This project implements a menu-driven Address Book system that allows users to manage contacts efficiently using file handling and structured programming concepts.

The application supports persistent storage using a CSV file and follows modular design principles.

---

## Features

- Add new contact  
- Search contact (Name / Phone / Email)  
- Edit contact  
- Delete contact  
- Load contacts from file  
- Save contacts to CSV  
- Menu-driven CLI interface  
- Modular architecture  

---

## Tech Stack

- C Programming Language
- GCC Compiler
- Makefile
- CSV File Handling
